Sync across devices

  1. Create a private GitHub repository to hold your data, for example expense-data.
  2. Create a fine-grained personal access token limited to that repository, with Contents set to Read and write.
  3. Enter the details here on every device you use. The token is kept in this browser only.

Export and backup

The CSV opens in Excel or Google Sheets. The backup file holds everything, including setup, and can be restored on any device.
